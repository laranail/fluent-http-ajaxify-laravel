# Security policy

## Reporting a vulnerability

Report vulnerabilities privately to **security@simtabi.com**. Please do not
open a public issue for a security problem.

Include the affected version, what an attacker can do with it, and the smallest
reproduction you have. You will get an acknowledgement within a few working
days.

> **Prefer GitHub private vulnerability reporting** when you can: open it from this
> repository's Security tab. The report arrives attached to the repo with a draft advisory
> and a CVE request path already in place. Email is the fallback for anyone who would
> rather not use GitHub.

## Supported versions

The latest released minor is supported. While this package is pre-1.0, that
means the most recent tag.
